## Repairs

- Zero or empty overlay dimensions now use valid fallback dimensions in the canvas, saved document and OBS source operations. A zero grid step could otherwise hang painting.
- Full-canvas catalog defaults are resolved to the current overlay dimensions when inserting a widget. Previously Emote Bouncer inserted string dimensions and crashed the canvas. Existing documents containing these strings are repaired in the editor's private copy on load.
- Overlay Save disables duplicate submissions, reports failures and permits retry. A completed save retains the dirty state of edits made during the write and republishes the current document state.
- Application document tracking no longer overwrites newer edits or resurrects a closed document when an older overlay save completes.
- Overlay size presets now schedule the same OBS source refresh as manual size edits.
- Graph Ctrl+F focuses the text input; match navigation retains text input focus.
- Graph toolbar Delete uses the application command and responds to annotation/invalid-link selections, matching keyboard deletion.
- Reviewed and refreshed the desktop graph golden: the original mismatch was 230 pixels at rounded panel corners, with no change to layout or content.
