# Product parity inventory

`docs/product-parity.md` is the human-readable inventory for product surfaces
that are broader than plugin contract extraction. The machine-readable source
is `docs/migration/product-surface.json`.

This directory is reserved for deterministic checks that can validate the
inventory without coupling the Flutter package to the TypeScript renderer.
The checker validates the manifest, requires a reason for every intentional
removal, compares the registered Flutter feature directories with the source,
and rejects removed Media Library markers. Plugin contract coverage remains
generated by `tools/parity/check.mjs`, while product-level visual and end-to-end
checks are added in their respective workstreams.

Run it from the repository root:

```powershell
corepack yarn parity:product
```

Every future checker should report one of the statuses used by the inventory:

```text
equivalent
improved
partial
intentionally_removed
not_applicable
```

An intentional removal must name the decision document that explains the
product impact and replacement, if any.
