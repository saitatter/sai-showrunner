# Product parity inventory

`docs/product-parity.md` is the human-readable inventory for product surfaces
that are broader than plugin contract extraction.

This directory is reserved for deterministic checks that can validate the
inventory without coupling the Flutter package to the TypeScript renderer.
The first check is intentionally documentation-backed: plugin contract
coverage remains generated by `tools/parity/check.mjs`, while product-level
visual and end-to-end checks are added in their respective workstreams.

Every future checker should report one of the statuses used by the inventory:

```text
equivalent
improved
partial
intentionally_removed
not_applicable
```

An intentional removal must name the decision document that explains the
product impact and replacement, if any.
